# 原神圣遗物强化模拟器

一个带图形界面的圣遗物获取 / 强化 / 评分模拟器，数值全部来自最初的 `基础数据.txt`（19 行词条表已内嵌进 `gasim/config.py`，**原始 txt 不在也能跑**），且**表格数值、圣遗物向量、概率与消耗参数都可以在界面里自定义**。

## 运行

双击 `启动.bat`，或在项目目录执行：

```
python main.py
```

需要 Python 3.10+（自带 tkinter）。开发环境为 `C:\Python314\python.exe`（Python 3.14.7 + tkinter 9.0）。

## 圣遗物向量（20 维）

| 位置 | 含义 |
| --- | --- |
| 1 | 套装 |
| 2 | 部位 |
| 3 | 主词条 |
| 4 | 等级 |
| 5 | 副词条数（**初始**副词条数量，3 或 4） |
| 6 | 目前词条数（**当前**副词条数量，3 或 4） |
| 7 / 8 | 祝圣定义词条 1 / 2（0 = 无） |
| 9~12 | 副词条 1~4 |
| 13~16 | 副词条初始成长 1~4 |
| 17~20 | 副词条升级成长 1~4 |

> 关于第 5、6 维：强化时「未满 4 条就抽一条新副词条」，因此必须知道**初始**有几条；而重掷次数由初始条数决定（初始 3 条 → 判定 4 次，初始 4 条 → 判定 5 次）。所以第 5 维记为初始条数、第 6 维记为当前条数。两维的显示名、顺序都能在「自定义 → 圣遗物向量」里改。

> 第 9~12 维（副词条 1~4）**总是填满 4 个词条**：超出第 6 维的那条就是「未激活词条」，它不影响评分与概率，只影响显示（见「未激活词条」一节）。

## 核心公式

- 主词条数值 = `(0.15 + 0.85 / 20 × 等级) × 该词条最大值`，+20 时正好等于最大值。
- 副词条数值 = `该词条最大值 × (初始成长 + 升级成长) ÷ 除数`。
  - **攻击力 / 生命值 / 防御力**（小词条）除数 = **16**；
  - 其余词条（含攻击力% / 生命值% / 防御力% / 元素精通 / 双暴 / 充能 / 伤害加成）除数 = **8**。
  - 两个除数都可在「自定义 → 参数」里改（`flat_substat_divisor` 与 `substat_divisor`），能用哪几个 key 走 16 由 `flat_substat_keys` 决定。
- 初始 3 条 : 初始 4 条 = **2 : 1**（权重 `{"3": 2.0, "4": 1.0}`，即 2/3 与 1/3）。
- 初始成长：`1 / 0.9 / 0.8 / 0.7` 四档等概率。
- 每 4 级（4/8/12/16/20）判定一次：未满 4 条则按权重不重复抽一条新副词条；已满 4 条则按「命中权重」选一条 +0.7 ~ +1.0。
- **第 4 条副词条在获取时就已经定好了**（词条名与初始成长都抽好，只是还没激活，见「未激活词条」一节）：强化到 +4 时直接启用它，不再重抽，所以分布与以前完全一致。

## 祝圣之霜

定义套装、部位、主词条、两个副词条，其余按规则生成。**初始副词条数与「获取新圣遗物」走同一套分布**（初始 3 : 4 = 2 : 1），两个定义词条始终占前两位；也就是说掷到 3 条时它就带 3 条初始副词条，掷到 4 条时带 4 条。

所选副词条**合计**至少强化命中 2 次（保底：当剩余判定次数不足以满足时强制命中该组）。

> 如果想让祝圣之霜固定出 4 条，把「自定义 → 参数」里的 *祝圣之霜 · 初始副词条数* 由 `0` 改成 `4` 即可（填 `3` 就是固定 3 条，`0` 表示跟随获取分布）。

消耗：生之花 / 死之羽 1 个，时之沙 2 个，理之冠 3 个，空之杯 4 个。数量不限。

## 启圣之尘

仅对 +20 满级圣遗物使用，选两条副词条重新强化（清空全部升级成长后按 4 或 5 次重掷）。**选好的两条会被记住**（按「第几条」记，不按显示文字），多次重塑、切换圣遗物同一件后仍是你选的那两条。

- **祝圣之霜定义件不能改要强化的目标**：如果这件圣遗物是用祝圣之霜定义的，那么「重新强化的两条副词条」必然就是当初定义的那两条 —— 界面上的两个下拉框会被禁用并显示「已锁定」，`engine.redeem_dust()` 也会忽略外部传入的下标，一律用定义的那两条。普通圣遗物不受影响，仍可任选两条。
- 每次使用都**至少保底 2 次命中**（`dust.min_total_hits`，普通件与祝圣之霜定义件一致）。
- **保底只在「本次消耗把进度推过阈值」的那一次生效**，阈值之间的那些消耗只有上面那 2 次基础保底：
  - 进度 + 消耗数 **首次达到 6 / 12** 的那一次 → 所选副词条至少命中 3 次；
  - 进度 + 消耗数 **首次达到 18** 的那一次 → 至少命中 4 次，随后**进度减去 18**（超出部分顺延到下一轮，所以进度始终落在 0~17）。
  - 举例：进度 5 时消耗 1 点 → 6，触发 3 次保底；进度已经是 6、再消耗 1 点到 7，**只**有 2 次基础保底。进度 17 时消耗 2 点 → 19，触发 4 次保底后进度变成 1。
  - 一个 18 点的完整循环里恰好触发 2 次 3 次保底与 1 次 4 次保底。
- **重塑后会弹窗对比「重塑前 / 重塑后」**，两边各显示评分、有效词条数与四条副词条，由你点「采用重塑前」或「采用重塑后」决定最终结果。默认高亮重塑后；直接关掉窗口等同于采用重塑后。
- 弹窗下半部还有 **「重塑过程」** 面板，逐次列出本次重掷的每一次判定（第几次判定、落在哪条副词条、加了哪一档成长）；命中的是本次所选那两条时行首带 `★`，末尾给出所选两条副词条的总成长变化与「共 N 次判定，落在所选两条上的有 M 次（保底要求 K 次）」的汇总。
- **选「重塑前」不会退回消耗**：启圣之尘的扣除与圣言解名进度已经计入，只是把副词条还原成重塑前的样子（成长与历史一并还原，历史里会留一条「保留了重塑前的结果」）。
- 18 是**保底阈值**，不是初始值；新开一局的进度是 0，存档里缺这个字段时也按 0 处理。
- **圣言解名进度可以直接改**：「启圣之尘」标签页里有「手动设置圣言解名进度」输入框 + **「设为该值」** 按钮，填 0 ~ 17 之间任意整数即可（超出范围会问你要不要改成最近的边界值），旁边另有 **「清零圣言解名进度」** 按钮。两者都只改进度，不动累计消耗数与圣遗物本身。
- 不想要弹窗的话，把「自定义 → 参数」里的 *启圣之尘 · 重塑后弹窗选择前后结果* 改成 `False`，就会总是采用重塑后的结果。

## 获取：先看，点按钮才入列表

「获取圣遗物」标签页的按钮行里有一个 **「加入圣遗物列表」** 按钮，**默认是灰的（不可点）**：

- **只点「获取」/「获取 10 次」= 先看着**：生成的圣遗物仍会完整显示在「获取结果」里（类型 / 名称 / 主词条 / 数值 / 等级 / 四条副词条 / 向量），但不会进列表、不写进存档；输出末尾会注明「以上 N 件尚未加入列表」，按钮变亮、下方的提示改成「待定 N 件」。
- **点「加入圣遗物列表」= 保存**：待定的这一批全部进列表并存档，最后一件自动成为「当前圣遗物」，按钮重新变灰。
  - 同时「圣遗物强化」页也会跟着切到这一件（不是停留在上一件），「强化过程」日志末尾会多出一条 `────…` 分界线 + `【加入列表】#编号 套装·部位 主词条 +等级`，方便一眼看出后面是新圣遗物的强化记录。
- **再点一次「获取」= 丢弃上一批**：待定的圣遗物会被新的一批替换掉，所以「看完不满意就再来一批」不会留下垃圾。
- 这个按钮只管「获取」，祝圣之霜生成的圣遗物一定入列（它是花霜换来的）；「获取后立即强化至满级」与它互相独立，所以可以「丢弃前先看一眼满级长什么样」。

### 获取计数

设置区最下面有一行 **`累计获取：N 件`**（蓝色）：

- 每获取一件就 **+1**，**丢弃的那批也算**（它确实被获取过），所以它统计的是「一共刷出来过多少件」，不是「列表里现在有多少件」。
- 计数跟着存档走（关程序再开还在），窗口右下角的状态栏也会写 `累计获取：N 件`。
- 想归零就按「说明」页的 **「清空存档（恢复出厂设置）」**，获取计数会和祝圣之霜 / 启圣之尘 计数一起清 0。

## 未激活词条（显示开关）

初始只有 3 条副词条的圣遗物，在获取那一刻其实已经把**第 4 条也定好了**（词条名 + 初始成长都抽好了，候选池与「+4 时才抽」完全一样），只是还没激活。

- **默认不显示、不计分**：和以前一样显示 `—`，第 5 维（初始条数）与第 6 维（当前条数）都还是 3，评分只算前 3 条。
- 打开「自定义 → 参数 → 显示设置」里的 **允许显示未激活词条** 之后：
  - 获取结果、详情弹窗、列表摘要里都会多出第 4 条，显示成灰色的 `[未激活 总成长=初始+升级] 词条名 +数值`（列表摘要里写 `未激活·词条名 +数值`）——它和已激活的词条一样有**初始成长**，数值就是 `最大值 × 初始成长 ÷ 除数`；
  - 它**不参与评分**（总分与「副词条总成长」都不变），但**命中评分规则时仍然 `★` 高亮**（词条名蓝加粗，其余灰字）。
- 强化到 **+4** 时启用的就是这条已经定好的词条（不会重新抽、初始成长也是当初那条的），所以开关只影响显示，不影响任何数值与概率。
- **关掉这个开关时**：列表里带未激活词条的圣遗物（等级 < 4）会**自动强化到 +4**把那条词条激活，历史里记一条「关闭「显示未激活词条」：自动强化至 +4 以激活第 4 条副词条」。本来就 4 条初始的圣遗物不受影响。
- **打开这个开关时**：会先给**背包里**（以及「获取结果」里还没加入列表的那批）还没预生成第 4 条的圣遗物补抽一条（同一套分布、排除主词条与已有副词条），所以老存档、手改过向量的圣遗物也能正常显示。
- 「获取结果」里那批**还没加入列表**的圣遗物同样吃上面两条规则：打开开关时补生成、关掉开关时同样自动 +4 并当场重画结果（等级、副词条、向量都会更新）。

> 「编辑向量」里若第 4 条填了词条、而「当前副词条数」写的是 3，只会提示「会被当成未激活词条」，不再判成错误。

## 圣遗物列表与向量编辑

「圣遗物列表」标签页列出全部圣遗物（ID / 名称 / 套装 / 部位 / 主词条 / 主词条数值 / 等级 / 评分 / 副词条）。

- **复制选中**：选中一件或多件后按「复制选中」（或右键菜单同名项），会按当前配置深拷贝一份——向量、套装/部位/主词条/等级/四条副词条与成长、保底信息、来源与备注、强化历史全部带走，只在历史末尾多一条「复制自 #原编号」。新件拿到新的紧凑编号，列表里立刻多出来并自动选中最后一件。复制件与原件完全独立，改其中一件不影响另一件。

- **ID 会在列表每次变更时重新编码为紧凑的 1…N**：新增、删除、清空、读档之后都会从头重排一遍，所以删掉中间几件不会留下空洞，编号也不会越删越大（`next_uid` 始终 = 当前件数 + 1）。代价是删除后其它圣遗物的编号会前移。

- 双击某一行 → 查看详情（含完整向量与强化历史）。

**评分相关显示**：列表里 **主词条 / 副词条** 两列会给有评分权重的词条加 `★` 前缀（主词条 `★暴击率`、副词条 `★暴击伤害 +7.00%`），右上角显示 `共 N 件　评分模式　最高分　平均分`，底部「评分明细」面板实时列出选中那一行的得分拆解（哪一条主/副词条各拿了多少分）。

- 选中后按 **「编辑向量」** 按钮（或右键菜单）→ 打开向量编辑器：20 个维度逐项可改，底部还有一个「整条向量」输入框，可以粘贴 `[6, 0, 2, 0, 4, ...]` 这样的文本后按「从文本读入」一次性填满。
- 按「确定」时先做自洽检查，任何一项不合格都会列出原因并拒绝写入：部位/套装 id 越界、主词条 id 不存在、等级超出 0~最大等级、副词条数与实际条数不符、副词条与主词条重复或彼此重复、初始条数大于当前条数、成长值为负。
- 写入后立即刷新列表、下拉框、评分与详情。改动会写进存档，并在该圣遗物的历史里留下一条「手动编辑向量」。

## 评分

每个套装各有一套规则，格式为：

```
套装名：词条名 主词条高亮 主词条得分系数 副词条权重
```

例：`来歆余响：暴击伤害 1 1.5 7.775`

- **第 2 个数字（主词条高亮）**：> 0 就把该词条**作为主词条时**加 `★` / 变蓝加粗；写 `0` 只是不高亮，**得分照算**。这是每条规则各自的开关；另外「自定义 → 参数」里还有两颗**全局**开关可以一键关掉所有 `★`（同样不影响得分），见下面「三个全局开关」。
- **第 3 个数字（主词条得分系数）**：主词条得分 = **等级 × 这个数**。上面的例子满级 +20 就是 30 分。
- **第 4 个数字（副词条权重）**：每条命中该词条的副词条按它计分。
- 省略规则：只写「词条名 高亮」时得分系数按 `1`；只写三个数时副词条权重取得分系数。
- **组名**：`各元素伤害加成`（也认 `所有元素伤害加成` / `元素伤害加成`）会一次性展开成 7 个元素伤害加成词条，权重相同，规则里只写一行就够；显示时仍写回组名。
- 一行可以写多条规则，用 `，` `,` `;` `；` 分隔。`通用：`（或 `默认` / `default`）是其余套装的兜底规则。

总分 = Σ（主词条得分 + 副词条得分）：

| 计分项 | 公式 |
|---|---|
| 主词条 | **等级 × 主词条得分系数**（+0 时是 0 分） |
| 副词条 | **副词条权重 × 总成长**（「按实际数值」模式则乘实际数值） |

两种副词条计分模式：

- **按总成长**（默认）：等价于「有效词条数」，不会因为单位不同而失真。
- **按实际数值**：副词条得分 = 权重 × 实际数值。

**默认模板是这三行**（已经写进每个套装）：`暴击率 1 1.5 7.775`、`暴击伤害 1 1.5 7.775`、`各元素伤害加成 1 0 0`——前两条满级主词条各 30 分、副词条每条 7.775，元素伤害加成只高亮不加主词条分（系数 0）。打开「评分」页就是当前套装自己的这几条规则，直接改、按「保存当前规则」即可，不用先「套用到全部」。想重置的话按 **「把内置默认模板套用到全部套装」**。旧版那五条模板（主 0.1 / 副 2 那套）会在读存档时**自动迁移**成这三行，自己改过的规则不会被覆盖。

### 三个全局开关（自定义 → 参数）

「自定义 → 参数」页最上面是「评分开关（全局）」，勾一下**立刻生效并落盘**，不用点「应用参数」：

| 开关 | 关掉之后 |
|---|---|
| **允许圣遗物评分** | 所有圣遗物得分一律显示 0，窗口右下角的评分模式变成「关闭评分」，列表统计写「评分已关闭」，各页【评分】块改为提示文字；重新勾上就恢复原分 |
| **允许主词条高亮** | 主词条行不再加 `★`（列表、详情、强化页、导出 CSV 都一样），**得分不变** |
| **允许副词条高亮** | 命中的副词条不再加 `★`，**得分不变** |

三颗开关都只影响「显示 / 计不计分」，配置存在 `config.json` 里，「清空存档（恢复出厂设置）」会把它们恢复成全部开启。

### 命中词条的高亮

开了高亮的词条会在所有文本里标出来：**主词条 / 副词条那一行加 `★` 前缀，并且整行变蓝加粗**；这件圣遗物到底命中了哪些词条、各按什么权重计分，会汇总在描述下面的【评分】块里：

```
【评分】总分 21.495（总成长模式）　有效词条数 1.80 / 副词条总成长 3.50
  ★ 命中：主词条 暴击伤害 每级 +1.5（★高亮）；副词条1 暴击伤害 ×7.775
  套装规则：暴击伤害★ 主1.5 副7.775、暴击率 主0.4 副2
```

套装规则里名字后面那个 `★` 就是第 2 个数字 > 0 的标记。列表页与导出 CSV 同样带 `★` 前缀（纯文本，粘到哪里都不会丢）。启圣之尘的重塑过程面板改用了 `◆`，表示「本次选中的那两条副词条」，不会和评分用的 `★` 混在一起。

### 各页面上的评分

- **圣遗物列表**：顶部统计最高分/平均分，行内 `★` 标记高亮词条，底部「评分明细」面板显示选中行的得分拆解（主词条那一条会写 `等级 20 × 1.5`）。
- **强化圣遗物**：右上角常驻 `当前评分 x.xxx　有效词条数 …　命中 N 条`；每次强化的日志末尾会写 `评分 a → b（+d）`，这一级吃到评分词条时还会列出命中项。
- **祝圣之霜**：选套装/主词条/两条副词条时，下方实时显示各自的评分权重（主词条会写「每级 +…（★高亮/不高亮）」）；生成后输出里带完整【评分】块。
- **获取结果 / 详情窗口 / 启圣之尘日志**：同样带 `★` 高亮与【评分】块。

## 自定义

- **数值表**：直接编辑文本，列顺序为 `名称 最大值 沙权重 头权重 杯权重 副词条权重 命中权重`，行号即主词条 id。支持导出 / 导入 txt。
- **套装与秘境**：左侧套装表可新增 / 重命名 / 上下移动 / 删除 / 恢复默认，右侧秘境表可新增 / 重命名 / 编辑掉落 / 删除 / 恢复默认。
  - 内置数据**截至 7.1 版本**：共 **46 个五星套装**（已剔除四星及以下套装）、**23 个副本**。套装名录与部件名取自 genshin-db 的简中数据集（原表 63 套，只保留含五星的 46 套），秘境掉落取自萌娘百科「原神/秘境」与 6.x / 7.x 版本攻略。
  - 序号就是向量里存的套装下标，所以调换顺序会让已存档圣遗物的套装名跟着变；删除中间一项会让后面的整体前移一位（程序会先提示）。
  - 重命名套装会同步搬走它的评分规则与部件名，并更新所有秘境里的引用；删除套装会一并删掉评分规则与秘境引用。
  - 秘境掉落用 `，,;；` 或空格分隔，未登记的套装名会被忽略并提示。
  - 秘境可以没有掉落（此时选它就从全部套装里随机），但要小心：`验收`/提示会点名这种空秘境。
- **部件名（圣遗物名称）**：选中一个套装后按「编辑部件名」，可以分别改这个套装里 **生之花 / 死之羽 / 时之沙 / 空之杯 / 理之冠** 五件圣遗物各自的名字。
  - 这个名字**不写进向量**，而是按 `(套装, 部位)` 现查现用——所以改了名字，存档里所有该套装的圣遗物显示会立刻跟着变（这正是它的好处：不用改存档）。
  - 留空会自动回落成「套装名·部位名」占位；「填入占位名」按钮可一键全部填占位。
  - 显示位置：详情 / 获取结果里的「圣遗物名称：…」一行、圣遗物列表的「名称」列、顶部「当前圣遗物」下拉框。
- **圣遗物向量**：上下移动调整排布、改显示名与说明；key 为程序内部语义，不可修改。
- **参数**：主词条成长公式、两个副词条除数（一般词条 / 小攻防生）及其适用的词条 key、初始与升级成长档位和模式、部位概率、强化间隔、祝圣之霜与启圣之尘的消耗和保底阈值、评分模式等，共 27 项。
- 配置可导出 / 导入 JSON；「恢复默认配置」可随时回到初始状态（套装与秘境也可单独「恢复默认」）。

## 清空存档（恢复出厂设置）

「说明」标签页左下角有一个 **「清空存档（恢复出厂设置）」** 按钮，点一下会把整个存档推倒重来：

| 会被清掉 | 恢复到 |
|---|---|
| 圣遗物列表 | **0 件**（编号也从 1 重新开始） |
| 获取计数（获取页的「累计获取」） | 0 |
| 祝圣之霜 / 启圣之尘 累计消耗数 | 0 |
| 圣言解名进度 | 0 |
| 评分规则（含各套装的规则与默认模板） | 内置默认模板（`暴击率 1 1.5 7.775` / `暴击伤害 1 1.5 7.775` / `各元素伤害加成 1 0 0`） |
| 三个全局评分开关 | 全部开启（允许评分 / 主词条高亮 / 副词条高亮） |
| 显示未激活词条 | 关闭（恢复成默认的只显示已激活词条） |
| 数值表、向量布局、套装、秘境、部件名、参数 | 全部初始值 |

- 点了会**连问两次**确认，确认后**立刻覆盖** `config.json` 与 `savegame.json`，不可撤销。
- 想留底请先「文件 → 导出配置」存一份 JSON，需要时再用「导入配置」读回来；圣遗物可以在列表页「导出 CSV」留个记录。
- 清空后界面上所有输出框、下拉框、评分明细、启圣之尘进度条都会同步刷新，可以直接接着用（新获取的圣遗物 ID 从 1 开始）。
